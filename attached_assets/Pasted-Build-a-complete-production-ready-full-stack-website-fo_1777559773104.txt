==============================================
BACKEND — REST API (Node.js + Express)
==============================================
Base URL: /api

PRODUCTS
  GET    /api/products              — get all products (supports ?category= and ?search= filters)
  GET    /api/products/:id          — get single product
  POST   /api/products              — create product (admin only, JWT protected)
  PUT    /api/products/:id          — update product (admin only)
  DELETE /api/products/:id          — delete product (admin only)

REVIEWS
  GET    /api/reviews               — get all reviews
  POST   /api/reviews               — submit a new review (public)
  DELETE /api/reviews/:id           — delete review (admin only)

MESSAGES (Contact Form)
  GET    /api/messages              — get all contact messages (admin only)
  POST   /api/messages              — submit contact form (public, sends email)
  DELETE /api/messages/:id          — delete message (admin only)

AUTH
  POST   /api/auth/login            — admin login, returns JWT token
  POST   /api/auth/logout           — logout (clear token)

Seed the database on first run with at least 8 sample products and the 2 real reviews above.

## AUTHENTICATION SYSTEM REQUIREMENTS

### 2. PAGES TO CREATE

- Email Address field
- Phone Number field (with UAE +971 prefix selector)

#### /forgot-password — Forgot Password Page

#### /account — My Account Page (protected, only accessible when logged in)

### 3. AUTHENTICATION LOGIC (use Supabase)
- Use Supabase Auth for all authentication (email + password)
- Store user profile (full name, phone) in a `profiles` table in Supabase
- Protect the /account route — redirect to /login if not authenticated
- Persist login session across page refreshes
- On logout, clear session and redirect to home
